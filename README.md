# 1934 경성 활판 인쇄소 (Gyeongseong Print Shop) - 3D 공포 게임 공간

1930년대 일제강점기 경성의 신문사 활판 인쇄소/식자실을 배경으로 한 **1인칭 3D 공포 게임 탐색 공간**입니다.  
레퍼런스 이미지의 고유한 분위기(어둡고 기름진 나무 바닥, 거대한 납 활자장, 흔들리는 백열전구, 멈춘 괘종시계, 피 묻은 앞치마 등)를 사실적으로 재현하였으며, 향후 다양한 기능(퍼즐, 이상현상, 공포 이벤트, 아이템 수집 등)을 손쉽게 추가할 수 있도록 모듈형 아키텍처로 구현되었습니다.

---

## 🎮 조작 방법 (Controls)

| 키 (Key) | 기능 (Action) |
|---|---|
| **화면 클릭** | 1인칭 시점 진입 및 마우스 포인터 잠금 |
| **W, A, S, D** / 방향키 | 1인칭 이동 (Movement) |
| **마우스 이동** | 시점 전환 (Mouse Look) |
| **Shift** | 달리기 (Sprint) |
| **C** / **Ctrl** | 웅크리기 (Crouch - 낮은 가구/선반 아래 탐색) |
| **우클릭** / **Z** | 시선 집중 및 확대 (Zoom / Focus) |
| **F** | 손전등 On/Off (Flashlight Toggle) |
| **E** | 사물 조사하기 (Inspect Object) |
| **ESC** / **E** | 조사 모달 닫기 (Close Inspect) |
| **H** | UI / HUD 표시 토글 (Toggle HUD) |
| **M** | 입체 음향 음소거 토글 (Toggle Mute) |

## 🏛️ 공간 구현 요소 (Implemented Space Features)

1. **중앙 식자 조판대 (Typesetting Workstation)**
   - 24개의 황동 손잡이 서랍이 달린 원목 대형 작업대
   - 납 활자가 정렬된 대형 조판 상판 (Galley Tray)
   - 먹물이 묻은 3D 잉크 롤러 (Brayer)와 식자봉
   - 1934년 10월 24일자 경성일보 호외 교정지 (『활판실 식자공 의문의 실종 사건』)
   - 서랍 선반 위에 놓인 저주받은 눈동자 활자 큐브 (`Vintage_metal_cube_with_eye`)

2. **거대한 활자 보관장 (Towering Type Cases)**
   - 높이 3.2m 이상의 대형 서가에 수만 개의 납 활자(한자/한글)가 꽂힌 그리드 매트릭스
   - 작업용 경사 식자대 및 노란 색인 라벨
   - 양쪽 벽면 및 깊은 안쪽 복도를 따라 배치되어 미로 같은 폐쇄 공포감 연출

3. **흔들리는 백열전구 & 조명 시스템 (Swinging Lamp & Lighting)**
   - 천장 보에서 늘어뜨려진 전선과 황동 소켓, 에디슨 전구
   - 미세한 기류에 의해 물리적으로 흔들리는 펜듈럼 회전 (그림자가 바닥을 따라 천천히 일렁임)
   - 주기적인 전압 강하 및 전구 깜빡임(Flicker)과 전기 스파크 버즈 음향
   - 전구 아래로 빛이 쏟아지는 부유 먼지 광원 원추 (Volumetric Dust Cone)

4. **1930년대 태엽 괘종시계 (Pendulum Wall Clock)**
   - 밤 11시 58분에 멈춘 시계바늘 (자정 2분 전)
   - 조화 진동(Harmonic Oscillation) 공식으로 흔들리는 황동 시계추
   - 시계추 반주기마다 정밀하게 동기화되어 울리는 입체 째깍거림 (`tick... tock...`)

5. **1934년 인쇄국 달력 (1934 Vintage Calendar)**
   - 1934년(소화 9년) 10월 빈티지 달력 포스터
   - 24일 날짜에 붉은 핏빛으로 굵게 쳐진 동그라미 및 흘려 쓴 낙서

6. **피 묻은 활판공 앞치마 & 둥근 안경 (Apron & Spectacles)**
   - 벽걸이 못에 걸린 삼베 작업 앞치마 (인쇄 먹물과 굳은 혈흔)
   - 두꺼운 철테 둥근 확대 안경 (유리 렌즈 반사)

7. **어두운 복도와 지하 윤전기실 철문 (Corridor & Heavy Door)**
   - 활자장 사이로 12m 이상 길게 뻗은 어두운 복도 (레퍼런스 영상 오마주)
   - 복도 끝에 쇠빗장과 자물쇠로 굳게 닫힌 【지하 윤전기실】 철문
   - 좌측 활자 선반에 놓인 머리카락 묶인 녹슨 열쇠

8. **Web Audio API 절차적 공포 음향 시스템**
   - 어둡고 낮은 저음 룸 톤 / 앰비언스 드론 (48Hz~51Hz 필터 스윕)
   - 나무 마룻바닥 발소리 및 불규칙하게 삐걱거리는 마룻바닥 소리
   - 괘종시계 째깍거림, 전구 깜빡임 버즈, 손전등 딸깍음, 조사 발견 스트링어

9. **공포 포스트 프로세싱**
   - 비네팅 (Vignette), 1930년대 필름 그레인 노이즈, 세피아 컬러 그레이딩

## 🛠️ 기능 확장을 위한 설계 가이드 (Extending Features)

"공간 구현 후 기능을 추가하려고 해"라는 개발 방향에 맞추어 다음 모듈들이 완벽히 분리되어 있습니다:

- **새로운 상호작용 오브젝트 추가**:
  `src/scene/Props.js` 또는 `src/scene/Furniture.js`에서 생성한 3D 메쉬의 `userData`에 다음과 같이 설정하면 즉시 레이캐스터와 연동되어 조사가 가능합니다.
  ```javascript
  mesh.userData = {
    isInteractable: true,
    name: '오브젝트 이름',
    description: '조사 시 나타날 설명 텍스트',
    type: 'puzzle' // 사용자 정의 타입
  };
  ```
- **이벤트 리스너 연동 (퍼즐/인벤토리/이상현상)**:
  `src/systems/InteractionManager.js`에서 오브젝트 조사 시 전역 이벤트 `space-inspect`가 발생합니다:
  ```javascript
  window.addEventListener('space-inspect', (e) => {
    const item = e.detail;
    console.log('조사한 아이템:', item.name, item.type);
    // 여기서 아이템 획득, 문 열림, 이상현상 트리거 등을 구현할 수 있습니다.
  });
  ```
- **실행 방법**:
  ```bash
  npm run dev
  ```
  브라우저에서 `http://localhost:5173/` 접속 후 화면을 클릭하여 플레이할 수 있습니다.
